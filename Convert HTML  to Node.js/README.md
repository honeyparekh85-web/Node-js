# HTML Website with React and Node.js

## About

This project converts the supplied website pages into React components. React Router displays the Home, About, Contact, and 404 pages. Express serves the built React website.

The Home, About, Contact, and 404 pages are React JSX components in `views/`. The website routes load these components directly.

## Technologies

- Node.js runs JavaScript on the computer and server.
- Express.js serves the built website.
- React builds the pages from reusable JSX components.
- React Router handles page URLs without full-page reloads.
- Vite runs the development website and creates the production build.
- CSS keeps the supplied website styling.

## Main Features

- Home, About, and Contact pages.
- React Router navigation and a custom 404 page.
- Original CSS and page content retained.
- Express serves the optimized production files.

## Install on Windows

1. Install the Node.js LTS version from [nodejs.org](https://nodejs.org/).
2. Open this folder in VS Code and open **Terminal > New Terminal**.
3. Check Node.js and npm:

   ```sh
   node -v
   npm -v
   ```

4. Install the project packages:

   ```sh
   npm install
   ```

`npm install` reads `package.json` and downloads Express, React, React Router, Vite, and the development tools.

## Run in Development

Run both the Express server and Vite development server with one command:

```sh
npm run dev
```

Open <http://localhost:5173>. Vite updates the React page as you edit. Express runs at <http://localhost:3000>.

## Build and Run with Express

Create the production website, then start Express:

```sh
npm run build
npm start
```

Open <http://localhost:3000>. Express serves the files generated in `dist/`.

## Test the Pages

Open `/`, `/about`, and `/contact`, and check navigation, styling, and the Learn More/Back to Home links. Open `/some-missing-page` to see the React 404 page. For production, run the build commands above before checking the site on port 3000.
